# SkyOS

SkyOS is a premium modular Minecraft Fabric ecosystem designed exclusively for Hypixel SkyBlock.

## Supported Versions

- Minecraft 1.21.10
- Minecraft 1.21.11

## Modules

### SkyOS-Core
Core framework providing:
- rendering systems
- overlay systems
- animation framework
- config framework
- module system
- networking helpers
- Hypixel detection
- inventory utilities
- storage systems

### Planned Modules
- SkyOS Storage Overlay
- SkyOS HUD
- SkyOS Utilities
- SkyOS Dungeons
- SkyOS Bazaar

## Design Philosophy

SkyOS focuses on:
- premium modern UI
- smooth UX
- modular architecture
- high performance
- Hypixel SkyBlock only
